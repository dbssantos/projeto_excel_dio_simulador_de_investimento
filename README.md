# 📊 Simulador Financeiro — DIO Investimentos

## 📌 Sobre o projeto

Este projeto consiste em um **simulador financeiro desenvolvido no Microsoft Excel**, criado como prática de organização de informações, aplicação de fórmulas e análise de dados.

A planilha permite simular aportes mensais e observar a evolução do patrimônio ao longo do tempo, além de apresentar uma sugestão de distribuição de investimentos em diferentes tipos de FIIs de acordo com um perfil de investidor.

> **Observação:** este projeto tem finalidade educacional e de demonstração de conhecimentos em Excel. Os valores e percentuais apresentados não constituem recomendação de investimento.

## 🎯 Objetivos

- Praticar o uso do Microsoft Excel em um projeto aplicado;
- Simular a formação de patrimônio por meio de aportes mensais;
- Comparar diferentes períodos de investimento;
- Utilizar fórmulas e operações matemáticas para automatizar cálculos;
- Organizar dados de acordo com diferentes perfis de investidor;
- Aplicar conceitos de análise e visualização de dados.

## 🛠️ Ferramentas e recursos utilizados

- **Microsoft Excel**
- **PROCV** para busca de informações em tabelas;
- **SOMA** para consolidação de valores;
- **Chave composta** para relacionar informações de diferentes critérios;
- **Divisões e cálculos percentuais** para distribuição dos valores;
- Referências de células;
- Formatação e organização de dados;
- Gráficos para visualização dos resultados.

## 📂 Estrutura do projeto

### `Planilha1`

A aba principal concentra o simulador e apresenta:

- Configurações de salário e rendimento;
- Sugestão de investimento mensal;
- Definição do período de investimento;
- Taxa de rendimento mensal;
- Estimativa de patrimônio acumulado;
- Simulações para diferentes períodos;
- Estimativa de dividendos;
- Distribuição sugerida por tipo de FII.

### `Planilha2`

A segunda aba funciona como uma **base de dados de apoio**, contendo percentuais associados aos diferentes perfis de investidor:

- Conservador;
- Moderado;
- Agressivo.

Os percentuais são organizados entre diferentes tipos de FIIs:

- Papel;
- Tijolo;
- Híbridos;
- Desenvolvimento;
- FOF's;
- Hotelarias.

A planilha utiliza **chaves compostas e PROCV** para localizar as informações correspondentes aos critérios definidos no simulador.

## 📈 Simulações

O projeto permite observar cenários de investimento em diferentes períodos, incluindo:

- 2 anos;
- 5 anos;
- 10 anos;
- 20 anos;
- 30 anos.

Dessa forma, é possível visualizar como o período de investimento e os aportes mensais influenciam a projeção de patrimônio.
